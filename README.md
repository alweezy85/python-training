# Python Training

A collection of Python practice files for learning the language from the ground up.

## Topics Covered

### `python_basics.py`
- Variables and assignment
- Strings and string operations
- Numbers and arithmetic
- Booleans and logical operators
- Lists
- Tuples
- Dictionaries
- Sets
- Type conversion
- Type checking

## How to Run

Make sure you have Python 3 installed, then run:

```bash
python3 python_basics.py
```

## Requirements

- Python 3.x
- No external libraries needed
